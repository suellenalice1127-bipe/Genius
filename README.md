# Jogo Genius (Simon) - HTML, CSS e JavaScript

Este projeto é uma recriação do clássico jogo de memória *Genius* (Simon), popular nos anos 80.  
O objetivo é repetir corretamente a sequência de cores e sons apresentada pelo jogo, aumentando o nível de dificuldade a cada rodada.

---

## Funcionalidades

- Sequência aleatória de cores e sons.
- Incremento automático de dificuldade a cada acerto.
- Feedback visual e sonoro para cada botão.
- Sistema de pontuação.
- Reinício automático após erro.
- Interface responsiva para desktop e mobile.

---

## Tecnologias Utilizadas

- *HTML5* → Estrutura do jogo.
- *CSS* → Estilização e animações.
- *JavaScript* → Lógica e interatividade.
